## 🧠 O que foi o AlfABC?

**AlfABC** foi um aplicativo open-source desenvolvido para ser uma ferramenta de apoio na alfabetização e no uso prático da leitura no dia a dia.  
Escrito inteiramente em Python, o app buscava oferecer funções simples e acessíveis para qualquer pessoa.

Este projeto está oficialmente **encerrado**, mas seu legado continua no **[Suno](https://github.com/Thonyy56/Suno)**, que expande e aprimora todas as ideias originais do AlfABC.

---

## 🔧 Funcionalidades

- 📖 **Leitor de Textos**: Lê textos digitados ou colados.
- 🖼️ **Leitor de Textos em Imagens**: Reconhece e lê textos presentes em imagens.
- 🧠 **Interpretação de Imagens**: Descreve imagens de forma simples para fácil compreensão.
- 🎯 **Foco na Alfabetização**: Interface pensada para ser intuitiva e amigável.
